We are excited to announce the launch of our brand new API documentation portal! 

This new platform is designed entirely with the developer experience in mind. Whether you are integrating our powerful Global Transfer services or utilizing the EFT to Turkish Banks capability, these updated docs aim to provide everything you need to get up and running quickly.

<!--truncate-->

## What's New?

### 1. Improved Integration Experience
We completely restructured our documentation. Instead of hunting through long PDFs, you can now explore the APIs interactively in this portal. 

### 2. Ready-to-use cURL and Multi-language Code Snippets
We've added direct `curl` functionality alongside our standard JSON examples. You'll find these tabs on every POST endpoint. For complex tasks like webhook HMAC signature verification, we've provided ready-made code examples in **Node.js**, **Python**, and **Java**.

### 3. Clear Process Flows
Where things get complicated—like in [Webhook Verification](/docs/eft-turkish-banks/webhooks) or achieving a [Multi-Currency Exchange](/docs/eft-turkish-banks/exchange)—we've integrated clear Mermaid sequence diagrams so that your team can visually understand the expected workflows.

### 4. Interactive Custom Components
Be sure to check out our [Error Codes](/docs/eft-turkish-banks/error-codes) page, featuring an interactive data table with smart filtering to help you identify and resolve API responses in seconds.

## Next Steps
