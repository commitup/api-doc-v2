# Create an EFT Transfer

Initiate a new EFT transfer to a Turkish bank account.

<ApiEndpoint method="POST" url="/eft-api/V2/transfer/create" />

:::tip Multi-currency Transfers
If you are sending funds in a different currency than your operating account (e.g., sending TRY from a USD account), you must first obtain an `exchangeId` from the **[Exchange](./exchange)** endpoint.
:::

**Request Parameters**

<Tabs>
  <TabItem value="table" label="Parameters" default>
### Transfer Request Parameters

| Parameter          | Required | Type   | Max Length | Description |
|--------------------|----------|--------|-----------:|-------------|
| amount             | True     | number |          - | The amount to transfer in the specified currency. |
| currency           | True     | string |          3 | Three-letter ISO 4217 currency code (e.g., TRY). |
| receiverAccount    | True     | string |         34 | The receiver's IBAN or account number depending on the transfer type. |
| receiverCardNumber | False    | string |         19 | The receiver's credit card number depending on the transfer type. |
| fromCountry        | True     | string |          3 | Three-letter ISO 3166-1 alpha-3 country code of the sender. |  
| receiverInfo       | True     | object |          - | Receiver information. See [EftPersonInfo](#eftpersoninfo). |
| senderExtFirmRefId | True     | string |         36 | Unique reference ID generated by the client system. |
| senderInfo         | True     | object |          - | Sender information. See [EftPersonInfo](#eftpersoninfo). |
| transferReason     | True     | string |          - | Reason for the transfer. See [EftTransferReason](#efttransferreason). |
| transferType       | True     | string |          - | Transfer method (`TO_IBAN` or `TO_CREDIT_CARD`). |
| comment            | False    | string |        250 | Optional remittance information. |
| exchangeId         | False    | string |          - | FX transaction reference ID for multi-currency transfers. See [Exchange](./exchange). |

### EftPersonInfo

Represents identity information of the transfer participant.
Used for both senderInfo and receiverInfo fields.



| Parameter           | Required For        | Type    | Max Length | Description                                                |
|---------------------|---------------------|---------|-----------:|------------------------------------------------------------|
| firstName           | Sender and Receiver | string  |         50 | The participant's first name.                              |
| lastName            | Sender and Receiver | string  |         50 | The participant's last name.                               |
| middleName          | Optional            | string  |         50 | The participant's middle name (patronymic, if applicable). |
| nationalCountryCode | Sender              | string  |          3 | Three-letter ISO 3166-1 alpha-3 country code.              |
| birthDay            | Sender              | string  |         10 | Date of birth in YYYY-MM-DD format.                        |
| birthPlace          | Sender              | string  |         50 | Place of birth.                                            |
| address             | Optional            | string  |        250 | The participant's address.                                 |
| addressCountryCode  | Optional            | string  |          3 | Three-letter ISO 3166-1 alpha-3 country code.              |
| company             | Optional            | boolean |          - | Whether the participant is a company. Default is false.    |
| countryPhoneCode    | Optional            | number  |          4 | Country phone code (e.g., 90 for Turkey).                  |
| phoneNumber         | Optional            | number  |         20 | Phone number without country code.                         |
| email               | Optional            | string  |        250 | Email address.                                             |
| identityNumber      | Optional            | string  |         50 | Identity / passport number.                                |

## EftTransferReason

Commonly used payment reasons (required for regulatory compliance).

| Value | Description |
| :--- | :--- |
| `HOME_RENT` | Home Rent |
| `OFFICE_RENT` | Office Rent |
| `OTHER_RENT` | Other Rent |
| `DUES` | Dues |
| `EDUCATION` | Education |
| `CREDIT_CARD_DEBT` | Credit Card Debt |
| `STAFF_PAYMENTS` | Staff Payments |
| `E_COMMERCE_PAYMENTS` | E-Commerce Payments |
| `OTHER_PAYMENTS` | Other Payments |
| `COMMERCIAL_PAYMENTS` | Commercial Payments |
| `INDIVIDUAL_PAYMENTS` | Individual Payments |
| `INVESTMENT` | Investment |
| `FINANCIAL` | Financial |
