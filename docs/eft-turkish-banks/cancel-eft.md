# Cancel EFT Transfer

Cancel an EFT transfer request that has not yet been processed by the recipient bank.

<ApiEndpoint method="GET" url="/eft-api/V2/transfer/cancel" />

## Overview

Only transfers in the **NEW** status can be cancelled. Once a transfer moves to `PENDING` or `COMPLETED`, it can no longer be cancelled through this endpoint.

---

## Path Parameters

| Parameter | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| transferOrderRefId | Yes | number | The unique reference ID generated by PayPorter for the transfer. |

---

:::info Result
If successful, the transfer status will change to **CANCEL** (Code 60). You should stop polling for updates for this transaction.
:::
