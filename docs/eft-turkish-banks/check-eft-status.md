# Check EFT Status

Check the current status of an EFT transfer using either your internal reference ID or the PayPorter reference ID.

## Check by External Firm Ref ID

Use this endpoint if you want to query the status using your own unique reference ID.

<ApiEndpoint method="GET" url="/eft-api/V2/transfer/check-status-by-ext-firm-id/{senderExtFirmRefId}" />

### Path Parameters

| Parameter | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| senderExtFirmRefId | Yes | string | Unique reference ID generated by your system. |

---

## Check by Transfer Order Ref ID

Use this endpoint if you want to query the status using the PayPorter reference ID.

<ApiEndpoint method="GET" url="/eft-api/V2/transfer/check-status-by-transfer-order-ref/{transferOrderRefId}" />

### Path Parameters

| Parameter | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| transferOrderRefId | Yes | number | Unique reference ID generated by PayPorter. |

---

## Response

The response format is identical for both endpoints.

<Tabs>
  <TabItem value="table" label="Response Parameters" default>

| Parameter | Type | Description |
| :--- | :--- | :--- |
| transferStatus | object | Detailed status information. |
| transferStatus.statusCode | number | Numeric status code. See [EFT Status Codes](./eft-flow#eft-status-codes). |
| transferStatus.statusName | string | Short name of the status (e.g., "Pending"). |
| transferStatus.statusDescription | string | Human-readable description of the status. |

  </TabItem>

:::info Final Status
Once a transfer reaches a **Final Status** (COMPLETED, REJECTED, REFUND, or CANCEL), it is recommended to stop polling this endpoint. For real-time updates without polling, consider implementing our [Webhook system](./eft-flow#best-practices).
:::

:::warning Rate Limiter
Individual status queries are subject to a rate limiter of **60 queries per minute**. For high-volume transaction monitoring, use the [Get EFT Transfer List](./get-eft-list) endpoint.
:::
