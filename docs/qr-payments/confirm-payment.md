# Confirm QR Payment

Initiate the payment or refund process after the user has reviewed the transaction details and provided confirmation.

<ApiEndpoint method="POST" url="/qrcode/payment/confirm" />

## Overview

After calling the `/read` endpoint and showing the details to the user, calling this endpoint will move the transaction to the `IN_PROGRESS` status. The final result will be delivered via webhook.

---

## Request Parameters

<Tabs>
  <TabItem value="table" label="Parameters" default>

| Parameter | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| transactionId | Yes | number | The unique transaction ID returned by the `/read` endpoint. |
| tenantReferenceId | Yes | string | A unique reference ID generated by the partner for this transaction. |
| amount | Yes | number | The amount to be paid (must match the QR amount unless it was a variable amount QR). |
| tenantUserId | Yes | number | The unique ID of the user in the partner's system. |
| tenantName | Yes | string | Name of the user. |
| tenantSurname | Yes | string | Surname of the user. |
| tenantNationality | No | string | Nationality of the user. |
| tenantBirthDate | No | string | Birth date of the user (Format: DD-MM-YYYY). |

  </TabItem>
  <TabItem value="request_example" label="Example Request">

```json
{
  "transactionId": 470023232,
  "tenantReferenceId": "08e6e4d3-7031-4f0a-bc90-3235aaa2600c",
  "amount": 11.50,
  "tenantUserId": 364,
  "tenantName": "Tahir",
  "tenantSurname": "incedere",
  "tenantNationality": "türkiye",
  "tenantBirthDate": "28-12-1996"
}
```

  </TabItem>
  <TabItem value="curl" label="cURL">

```shell
curl -X POST https://apilist.payporter.com.tr:81/online/qrcode/payment/confirm \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{ "transactionId": 470023232, "tenantReferenceId": "08e6e4d3-7031-4f0a-bc90-3235aaa2600c", "amount": 11.5, "tenantUserId": 364, ... }'
```

  </TabItem>
</Tabs>

:::warning Async Processing
The response `status: "IN_PROGRESS"` means the request was accepted. You must listen for the **Webhook** to get the final status (**COMPLETED** or **FAILED**).
:::
