# POS API Genel Bakış

POS API (Sanal POS), doğrudan entegrasyon veya barındırılan bir ödeme sayfası (hosted checkout) aracılığıyla kartlı ödemeleri kabul etmenize olanak tanır. Doğrudan ödemeleri, ön provizyonu, 3D Secure kimlik doğrulamasını ve taksit seçeneklerini destekler.
