# Модели данных EFT

Справочное руководство по общим моделям данных, используемым в EFT API.

## EftPersonInfo

Используется для представления личной информации как отправителя, так и получателя.

| Свойство | Тип | Описание | Пример |
| :--- | :--- | :--- | :--- |
| firstName | string | Имя (имена) | `John` |
| lastName | string | Фамилия | `Doe` |
| identityNo | string | Номер удостоверения личности или паспорта | `12345678901` |
| identityType | string | Тип удостоверения (например, `TC_IDENTITY`, `PASSPORT`) | `TC_IDENTITY` |
| birthDate | string | Дата в формате ISO | `1985-05-15` |
| nationality | string | Код ISO 3166-1 alpha-3 | `TUR` |
| address | string | Полный физический адрес | `Ataturk Cad. No:1...` |
| city | string | Город проживания | `Istanbul` |
| phone | string | Контактный номер | `+905551234567` |

---

## EftAccountInfo

Используется для хранения информации о счете или карте.

| Свойство | Тип | Описание | Пример |
| :--- | :--- | :--- | :--- |
| accountNickName| string | Понятное имя для счета | `Мои сбережения` |
| accountNo | string | IBAN или номер карты | `TR1234...` |
| branchCode | number | Код филиала банка | `123` |
| suffixNo | number | Суффикс счета (если применимо) | `5001` |

---

## EftTransferType

Определяет пункт назначения денежного перевода.

| Значение | Описание |
| :--- | :--- |
| `TO_IBAN` | Перевод на банковский счет по IBAN. |
| `TO_CREDIT_CARD`| Перевод непосредственно на номер кредитной карты. |

---

## EftTransferReason

Часто используемые причины платежей (требуются для соблюдения нормативных требований).

| Значение | Описание |
| :--- | :--- |
| `HOME_RENT` | Арендная плата за жилую недвижимость. |
| `OFFICE_RENT` | Арендная плата за коммерческую недвижимость. |
| `EDUCATION` | Плата за обучение или курсы. |
| `STAFF_PAYMENTS` | Заработная плата. |
| `COMMERCIAL_PAYMENTS` | Оплата товаров и услуг. |
| `FINANCIAL` | Инвестиционные или общие финансовые переводы. |
| `OTHER_PAYMENTS` | Общая причина платежа. |
