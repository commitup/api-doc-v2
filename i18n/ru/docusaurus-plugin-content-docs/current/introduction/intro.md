# Введение

Этот API служит основным шлюзом для осуществления денежных переводов через платформу PayPorter.
Money Transfer API организован в соответствии с принципами [REST](https://en.wikipedia.org/wiki/Representational_state_transfer).

**Базовый URL:**
```
https://online-mig.payporter.com.tr:8586/online
```

[Скачать нашу коллекцию Postman можно здесь](https://apilist.payporter.com.tr:81/online/doc/payporter-postman.json)

## Общая информация об API

### Токен доступа (Access Token)
Все эндпоинты требуют Bearer токен в заголовке Authorization. Вы можете получить токен, вызвав эндпоинт `/login` с вашими учетными данными. Вам следует хранить этот токен до истечения его срока действия. Когда срок действия токена истечет, вам нужно будет сгенерировать новый.

:::caution **Важно**
Пожалуйста, не вызывайте login перед каждым запросом. В противном случае вы получите ответ `HTTP 429 Too Many Requests`.
:::

### Ответы и ошибки
- **Успех:** Если запрос выполнен успешно, вы получите ответ `HTTP 200 OK`.
- **Ошибки клиента:** Если запрос не выполнен из-за неверных параметров или структуры, вы получите ответ `HTTP 4XX`.
- **Бизнес-ошибки:** В случае бизнес-ошибок вы получите ответ `HTTP 406`, где поле `success` в теле ответа будет иметь значение `false`. Поле `messageCode` будет заполнено кодом ошибки. Вам необходимо проверить уникальный `messageCode`.
- **Ошибки сервера:** Ответ `HTTP 500 Internal Server Error` означает наличие проблемы на сервере. Пожалуйста, проверьте статус вашего перевода или платежа перед повторной попыткой запроса.

Если вы получите `LOGOUT` в поле `messageCode` от любого эндпоинта, вам следует снова вызвать эндпоинт login, чтобы получить новый токен. При `LOGOUT` вы можете получить ответ `HTTP 401 Unauthorized` или `HTTP 406`.

### Структура ответа
В этом API структура ответа строго соответствует следующему формату:
```json
{
  "body": {
    "responseObject": { 
      // ... 
    },
    "restHeader": {
      "code": "string",
      "message": "string",
      "success": true,
      "messageCode": "string"
    }
  }
}
```

### Ограничение частоты запросов (Rate Limiter)
В этом API есть ограничитель частоты запросов. Если вы превысите лимиты, вы получите ответ `HTTP 429 Too Many Requests`.
