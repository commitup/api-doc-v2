# Статусы перевода

Коды статусов и описания для операций денежных переводов.

| Код | Описание |
| :--- | :--- |
| `WAITING_APPROVAL` | Ожидает одобрения |
| `WAITING_FOR_PAYMENT` | Ожидает оплаты |
| `PAID_OUT` | Выплачено |
| `CANCELLED` | Отменено |
| `REFUNDED` | Возвращено |
| `EXPIRED` | Срок действия истек |
| `ON_HOLD` | В ожидании (проверка комплаенса) |

---

:::info Комплаенс
Операции со статусом `ON_HOLD` требуют ручной проверки. По завершении проверки статус обновится автоматически.
:::
