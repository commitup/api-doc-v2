# Считать QR-код

Отсканируйте QR-код продавца и получите детали транзакции (имя продавца, сумма и т.д.).

<ApiEndpoint method="POST" url="/qrcode/payment/read" />

## Обзор

Эта конечная точка обрабатывает необработанные данные QR-кода и возвращает подробную информацию, необходимую для инициирования процесса оплаты. Поддерживаемые типы транзакций включают стандартные платежи и запросы на возврат.

---

## Параметры запроса

| Параметр | Обязательно | Тип | Описание |
| :--- | :--- | :--- | :--- |
| qrData | Да | string | Необработанные данные отсканированного QR-кода. |
